Built by Parv Jain
Data was cleaned in Python (pandas) — standardizing categorical text, correcting invalid ages and impossible admission/discharge sequences, stripping currency formatting from billing values, capping billing outliers at the 99th percentile, and removing duplicate records — before this dashboard was built as static SVG and vanilla JavaScript, with no charting library or external dependency.
